### 本轮解决的问题与保留边界

- 「内容版本」实际是可继续修改的内容组合，并不是历史快照；共享块更新还能改变多个版本。用“版本”同时暗示“不同用途的稿件”和“过去的记录”，容易误解。
- 归档与备份曾合用一个入口，混合了单份工作稿与整库维护。已确认收敛为「归档」与独立「归档库」，移除备份恢复；后续整体设计沿用此边界。
- 区域检查改为原模板任务，已衔接导入引导与完整问题列表，零文稿模板也有明确入口。
- 文稿列表和当前稿操作统一新建、另存、改名、删除与换模板；正文编辑、素材和插入操作汇入字段侧栏，独立归档库保留查找职责。
- 正文默认只改当前稿，素材编辑／删除显式勾选引用范围；未勾选字段保留独立文字，避免两个入口产生不明朗的共享影响。

### 统一的对象

| 对象与简短说明 | 负责什么 | 现有能力如何承接 |
|---|---|---|
| 文稿：针对一种用途持续编辑的文档 | 选择模板、替换内容、局部修改、排版、导出 | 现有 version + bindings + 版本排版动作；不新建平行文稿表，不重编号旧记录，必要的行为增量见兼容表 |
| 模板：版式和可编辑区域 | 原 DOCX、区域识别／确认／排除／补选／微调 | 现有 template + regions，不承载某次投递的具体内容 |
| 素材：可以复用的文字内容 | 内容块、标签、搜索、模板库成员和引用关系 | 现有 blocks；“加入当前模板”与“用于当前文稿”分别表达，不混为绑定 |
| 归档：保存此刻的 Word 和 PDF | 搜索、查看、下载、显式删除，不随后续编辑改变 | 现有 archives；从当前工作稿归档，独立归档库管理，来源删除后仍保留（本轮已确认） |

“不同用途”用“另存为文稿”；“保存当时结果”使用“归档”。撤销／重做继续承担当前编辑会话的纠错，不再增加一个平行的“内容历史”入口。

归档和可编辑工作稿不合成一个冻结状态：同一工作稿可以继续修改并归档多次；来源删除后归档仍需可查。当前归档只有产物与来源描述，**不保证能完整恢复为可编辑工作稿**；“从归档继续编辑”若以后需要，必须单独设计并保存完整编辑快照和模板原件，不能用下载文件假装恢复。

### 前端组织与主路径

主导航为「文稿／模板／素材／归档库」，帮助与服务状态放入辅助菜单。首页文稿列表按模板分组，可展开／收起，每组显示所含文稿并直接使用该模板新建；组内可继续编辑、另存和删除。零文稿模板仍可找到并新建；原型不再提供首页方案比较控件。

首版不显示“最近编辑时间”：当前 versions.updated_at 只覆盖创建与重命名，绑定、排版及共享文字修改不一定更新它。若以后需要按最近编辑排序，须先定义并验证真实内容修改时间，不能将旧字段直接改标签。归档关联使用已有 source_version_id，来源不存在时仍显示独立归档，不能按名称猜测。

日常主路径为：选择或新建文稿 → 编辑文字／选用素材 → 查看实时预览与问题提示 → 导出或归档。已有模板可直接复用；首次导入模板进入区域检查引导。

编辑页：

- 顶部明确当前文稿名、所用模板和保存状态；主动作是“导出”，相邻提供已确认的“归档”。普通导出不自动制造归档记录。
- 宽屏默认只显示成品预览；点击正文后在旁边打开一个编辑面板，文字、选用素材和局部排版在此处完成。问题与视图工具按需展开，不同时常驻多个侧栏。窄屏采用同一上下文的抽屉，保持当前选区和未保存输入。
- 当前文稿可提供进入相关归档的快捷方式；归档库继续独立管理全部归档，包括来源已删除的记录，不要求先进入某份文稿。
- 选区点击直接进入编辑栏，“设定为素材”放在“选用素材”左侧。选用素材在同一竖栏替换编辑面板，文稿保持可见，不用整屏遮罩；返回保留未提交文字。窄屏上下排列，仍可浏览文稿。
- “插入与排版”提供上方／下方插入空行；新增行有独立身份、绑定和编辑能力，原字段不被清空或挪用。删除／恢复段落、换行等原有能力保留，但不再用“留白”代指插入。缩放、图例放在预览视图工具中。
- “更换模板”用于把当前文稿文字套到另一种版式：选择新模板 → 查看套用预览 → 生成新文稿。界面不显示“自动匹配／候选／同类型”等内部术语；已能放入的文字直接展示，尚未安排的逐段显示真实文字，点击新模板位置放置，或明确选择“本次不带入”。可调整已放入的位置，不覆盖已占用位置，不静默丢弃。浏览模板不触发套用，原稿与其他文稿均保留。
- 导出前汇总缺失绑定、溢出和当前区域问题，点击可定位；大超出仍按 D5 显式确认。普通信息不重复弹窗，错误在发生处解释并可重试。

### 五条操作路径与返回规则

| 任务 | 最短路径与明确按钮 | 取消、失败和适用范围 |
|---|---|---|
| 新建文稿 | 文稿 → 新建文稿 → 选已有模板或导入 → 命名 → 开始编辑 | 已有模板不强制重复检查；导入后提供“检查区域”和“稍后检查，开始编辑”。取消新建不产生空白文稿，已成功导入的模板保留在模板库 |
| 日常改稿 | 打开文稿 → 点击正文 → 输入文字或“选用素材” → 保存到当前文稿 | 默认不改其他文稿；未保存离开时保留输入或显式放弃。更新共享素材走独立确认，先展示真实引用影响 |
| 检查模板 | 文稿 → 检查区域 → 在原模板画布浏览、确认或添加区域 → 完成，返回文稿 | 添加并入检查任务，在同一原模板画布直接框选；逐项保存，可中断续作。补选默认保存并返回，另有继续添加；回到原文稿、缩放和滚动 |
| 更换模板 | 当前文稿 → 选新模板 → 查看套用结果，点选尚未安排文字的放置位置 → 生成新文稿 | 每次创建新稿，原稿和目标已有文稿保留；取消不建稿。同管线生成临时预览，不以浏览器排版代替实际产物。文字须已放入或被明确选择不带入，新稿重名、区域变更或保存失败原处重试 |
| 保存成品 | 当前文稿 → 归档 → 命名并保存 → 归档详情 | 保存独立 Word／PDF；原稿继续编辑。普通导出只下载 Word。删除来源不影响归档，归档删除单独确认；查看归档不进入编辑模式 |

模板库可独立导入和检查模板，不自动制造一份“默认文稿”；从模板卡片点击“用此模板新建”才创建文稿。该行为已随主体方案确认，与当前实现的差异及兼容方式见下表。

保存反馈与预览反馈分别表达：“内容已保存”不代表“新预览已就绪”。转换中保留旧预览，失败给出重试；保存失败保留输入，不能显示已保存。切换文稿／模板的旧响应不得覆盖新上下文。按钮忙碌时禁止重复提交，完成后恢复触发处或新页面标题附近的合理焦点；Escape 先关闭内层菜单，再处理外层抽屉。

文稿问题只汇总当前稿缺失绑定与溢出，并给模板问题入口；模板任务完整列出待检查、已排除、未定位、不可选，已排除是可查看的决定，不冒充错误。沿用 D5 的大超出确认；素材同步删除后的留空字段按下述新增确认规则提示，不强制先填完才允许输出。

### 素材管理与引用影响（2026-10-21 补充确认）

- 素材库提供新建、编辑、删除、搜索与标签，批量管理支持当前可见范围全选、清除、批量标签和删除；失败项保留选择并展示原因，不能把隐藏筛选结果一起删除。
- 编辑／删除前展示仍引用该素材、未个性化的文稿字段，提供同步开关与具体字段选择；默认保留文稿。个性化修改已换绑独立块，始终不覆盖，不按文字相等猜测仍在引用。既有归档始终不随素材变化。
- 编辑不同步的字段保留原文并转为独立内容；仅改素材名称／标签时不必复制或断开正文引用。同步所选字段时仍保持素材引用，后续可继续按同样规则选择范围。
- 用户已确认同步删除的处理：所选字段留空、保留字段位置，以高亮边框和“素材已删除，待补内容”表达；不删除整段。未选同步与个性化字段保留文字并解除素材关联。
- 导出和归档前汇总此类留空字段，可逐项定位、返回补全或显式确认仍然输出；取消不产生文件或归档。归档确认记录当时的缺失提示，后来补全来源不会改变旧成品。提示必须覆盖同一内容批次，不能仅依赖按钮前的过期前端计数。
- “设定为素材”保存编辑框当前文字为新素材并关联当前字段，名称和标签在同一侧栏填写；已有素材不被静默覆盖。只有保存成功才同时建立关联，失败保留输入，不能遗留孤素材或半次绑定。

### 独立插入行与原模板检查

- 插入空行归属当前文稿。上／下插入后原字段内容不变，新行可点击、绑定素材、编辑、再插入和删除；各行使用稳定身份及明确顺序，不能共用原区域的单一绑定。
- 当前 bindings 的 UNIQUE(version_id, region_id) 与 position 仅能给同一区域安排一份绑定，不能承接多条独立插入行。M40c 增加版本级插入行记录与统一字段视图，复用 blocks 内容；不把插入行写入模板 regions，不改变旧 position 的解释。字段身份同时包含类别与 ID，旧区域接口保留，新增插入行接口承接新能力。
- 插入行复制、顺序、独立修改／共享同步、删除／恢复、撤销、缺失提示、溢出定位、归档及同源 DOCX／PDF 管线需一起验证；默认名不因删行复用。原段落或模板区域删除的依赖应显式处理，不能静默吞掉仍有内容的插入行。换模板的无匹配清单须包含无法映射的插入行，不可直接遗失。
- 检查任务直接使用模板原文 PDF、缩放与翻页；“添加区域”在该任务内启动，仍在同一画布框选。命名／类型只在旁栏编辑，不另造脱离模板的小卡片。保留单段框选、区域身份、排除与不可选规则，重新框选保留输入；保存一次返回文稿，另提供继续添加。
- 归档列表与详情均提供“删除归档”，单独确认，只删除该份产物，不影响来源文稿或其他归档。该能力已在生产应用存在，本次是补齐原型入口与整体导航承接。

### 区域检查的现行衔接

检查内添加、导入引导、完整问题列表及独立模板检查已实现。检查直接显示原模板 PDF，命名内嵌画布，不再用独立小预览；返回路径区分模板页与当前稿。

- 导入后接续区域检查引导，展示待检查数量和下一步；沿用已有逐项保存与中断续作能力。
- 完整问题列表汇总待检查、已排除、未定位及不可选区域，定位到具体对象；与已实现的下一处检查、补选、调整、删除和重新检查衔接。
- 批量确认必须展示范围并由用户触发；不因置信度高就静默改变人工确认状态。
- 后续独立模板设置页与文稿编辑页进一步明确对象和返回路径，沿用模板本体与成品预览分工；内部 proofread 状态可继续复用。
- 日常编辑只提示相关待检查问题，不强迫每次导出都重走全部区域确认。哪些问题阻止导出沿用已确认规则；新增硬性阻断另行确认。

### 实施顺序与验收

归档、维护、界面精简和区域检查任务已按上述局部确认范围实施；以下整体重整已确认，编号不表示已完成。每个模块先修 bug，再以类型检查、lint、相关测试和实际浏览器操作验收后进入下一个模块。

| 模块 | 最小交付 | 可验证标准 |
|---|---|---|
| M37 统一职责与交互原型 | 确认术语、完整功能映射、文稿／模板／归档库线框和关键状态 | 每项现有功能有唯一主入口；走通首次导入、日常改稿、换模板和归档下载；明确哪些 API／数据契约需新增 |
| M38 文稿入口与上下文统一 | 先按模板分组的文稿列表与导航，再模板独立存放／新建，再可视套用并创建新稿，最后串联已有归档来源；每步独立验证 | 旧资料库无需重建、旧默认稿保留；取消不建稿，更换模板按结果预览安排文字且不覆盖；来源删除后归档可下载；普通导出不增加归档 |
| M39 模板准备与问题定位 | 先原模板检查画布与内嵌添加，再导入引导和完整问题列表 | 同一原模板上浏览与框选；待检查、已排除、未定位及不可选范围可解释；返回原稿、逐项保存与中断续作保持 |
| M40 素材与选区操作统一 | 先引用影响与缺失提醒，再素材增删／批量、侧栏选用／设定，最后独立插入行 | 仅同步所选未个性化字段；不同步保留文字；同步删除留空高亮且输出提示；上下插入不占原绑定，单管线产物一致 |
| M41 整体验收与分发衔接 | 全量回归、宽窄屏、键盘／焦点、公开 Word 样本与更新迁移验证 | 同源预览导出一致；3–5 份实际 DOCX 人工比对并说明来源与样本局限，不冒称用户真实简历；两架构正式分发另满足签名与干净机器验收 |

M38 的最小顺序为：M38a 文稿视图模型与列表 → M38b 主导航和当前文稿上下文 → M38c 模板独立保存及显式新建 → M38d 更换模板新稿模式 → M38e 归档来源快捷关联。每一步先补相关缺陷，再完成类型、lint、相关测试及前端操作验证；不能把五步打包后才检查。M39、M40 继续各自按任务／选区边界小步推进。

M38—M41 本轮源码与代理验收已完成。后端 408 项、前端 368 项、类型／lint／构建、320／850 像素及桌面操作、四份公开 DOCX 的所有五页人工比对通过；代码提交 1abe2d0 的远程五项 CI 全部通过，记录见 TODO。样本来源及一致性结果见开发验证规范；固定标签下载包未更新。

优先复用当前模板／版本／绑定／归档 API，以前端视图模型组织文稿。新行为用兼容的显式模式承接，不直接重命名数据库。文稿身份与归档来源已有稳定 ID；“从归档继续编辑”另需完整快照，不在本轮实施。旧归档无法可靠关联时仍保留为独立记录。

整体重整的操作目标：打开文稿后直接点击正文编辑；从正文一处进入所需素材和局部排版；工作稿旁可归档，归档库可独立搜索、查看和下载；日常改稿导出流程无需切换校对开关。性能沿用 D12 的现行验收口径：2026-10-21 用户已按当前实测验收本轮优化，原一秒目标不再阻塞本期，继续保留真实测量、旧预览与等待反馈。
